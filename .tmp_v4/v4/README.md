بعد از جایگذاری `schema.prisma`:
```bash
npx prisma db push
npx prisma generate
```

## چیزی که باید دستی انجام بدی: پوشه آپلود

فایل‌های آپلودی داخل `public/uploads/` ذخیره می‌شن. کد خودش این پوشه رو در صورت نبودن می‌سازه، اما بهتره از قبل به `.gitignore` اضافه‌ش کنی تا فایل‌های آپلودی کاربران وارد گیت نشن:
```
public/uploads/
```
اگه هاستینگت (مثل بعضی پلتفرم‌های serverless) فایل‌سیستم فقط-خواندنی داره، آپلود مستقیم روی دیسک کار نمی‌کنه — اما چون از قبل با SQLite (که خودش فایل روی دیسکه) کار می‌کنی، به‌احتمال زیاد روی سرور خودت (self-hosted) هستی و مشکلی نیست.

## خلاصه‌ی قابلیت‌های جدید

### پنل مجزای منتور
با ورود یک کاربر با نقش `MENTOR`، به‌جای داشبورد دانشجو، پنل کاملاً جدا و اختصاصی باز می‌شه:
- **نمای کلی**: تعداد پروژه‌ها، تیم‌های اختصاص‌یافته، تسک‌های در انتظار تایید
- **پروژه‌های من**: برای هر پروژه یک کارت با:
  - تیم اختصاص‌یافته و اعضایش
  - **تایم‌لاین/تسک‌ها**: منتور تسک اضافه می‌کنه؛ وقتی سرپرست تیم تسک رو «انجام‌شده» علامت بزنه، منتور می‌تونه تاییدش کنه یا برگردونه
  - **فایل‌های پروژه**: منتور می‌تونه فایل مخصوص همون پروژه آپلود/حذف کنه
  - **گزارش‌های پیشرفت تیم**: هر گزارشی که سرپرست تیم ثبت کرده، اینجا دیده می‌شه

### تعمیر پیکربندی سیستم
تاگل‌های «ثبت‌نام دانشجو»، «انتخاب پروژه» و «حالت تعمیر و نگهداری» حالا واقعاً ذخیره و اعمال می‌شن:
- اگه «ثبت‌نام دانشجو» خاموش باشه، `POST /api/auth/register` درخواست‌های جدید رو رد می‌کنه.
- اگه «انتخاب پروژه» خاموش باشه، `POST /api/projects/apply` رد می‌کنه.
- ⚠️ «حالت تعمیر و نگهداری» فعلاً فقط ذخیره می‌شه ولی هنوز کل سایت رو قفل نمی‌کنه (چون نیاز به تغییر در middleware داشت که ریسک بیشتری داره). اگه می‌خوای این‌ رو هم واقعاً فعال کنم، بگو.

### تغییر منتور یک پروژه
تو تب «پروژه‌های فعال» پنل ادمین، کنار هر پروژه یک Select با لیست منتورها هست؛ انتخاب یک منتور جدید فوراً پروژه رو به‌روزرسانی می‌کنه.

### مدیریت کامل برنامه زمان‌بندی
تب جدید «برنامه زمان‌بندی» در پنل ادمین: افزودن، ویرایش، حذف رویدادها (که همون رویدادهایی هستن که تو صفحه اصلی سایت هم نمایش داده می‌شن، چون از یک جدول میان).

### آپلود/دانلود فایل
- **فایل عمومی**: تب جدید «فایل‌ها» در پنل ادمین؛ هر چی آپلود بشه، تو تب «دانلودها»ی داشبورد دانشجو دیده می‌شه.
- **فایل مخصوص پروژه**: هر منتور فقط برای پروژه‌ی خودش آپلود می‌کنه؛ این فایل‌ها تو تب «پروژه من» دانشجوهای همون تیم دیده و قابل دانلود می‌شن.
- حداکثر حجم فایل: ۵۰ مگابایت (قابل تغییر در `src/app/api/resources/upload/route.ts`، متغیر `MAX_FILE_SIZE`).

### بروزرسانی پروژه (واقعی شد)
دکمه «ثبت به‌روزرسانی» (فقط برای سرپرست تیمِ پذیرفته‌شده) یک دیالوگ باز می‌کنه که متن گزارش رو می‌گیره و ذخیره می‌کنه؛ این گزارش‌ها هم تو داشبورد دانشجو («گزارش‌های پیشرفت») و هم تو پنل منتور («گزارش‌های پیشرفت تیم») دیده می‌شن.

### نمایش منتور/ادمین در لیست کاربران
تب «کاربران» پنل ادمین حالا همه‌ی نقش‌ها رو نشون می‌ده (نه فقط دانشجو)، با بج رنگی برای هر نقش. دکمه «ارتقا به منتور» فقط برای کاربرانی که هنوز `PARTICIPANT` هستن نشون داده می‌شه.

### رفع لینک‌های درباره ما/تماس/حریم خصوصی
مشکل از `footer.tsx` بود — لینک‌ها `href="#"` بودن (یعنی به هیچ‌جا وصل نبودن). الان به `/about`، `/contact`، `/privacy` وصل شدن با کامپوننت `Link` درست (چندزبانه).

## چیزهایی که هنوز دست نزدم (چون فایلش رو ندیدم یا خارج از این مرحله بود)

- **بخش آموزش (`/learn`)**: دیدم که از `db.course` و `db.resource` می‌خونه (نه از `tutorials.ts` که یک فایل داده‌ی ثابت و بلااستفاده است). آپلود فایل برای درس‌ها (`Lesson`) رو وصل نکردم چون فایل `learn-client.tsx` رو ندیدم و نمی‌خواستم بدون دیدنش حدسی چیزی عوض کنم. اگه بخوای این بخشم بشه (منتور برای درس‌ها فایل آپلود کنه)، اون فایل رو بفرست.
- **قفل واقعی سایت با حالت تعمیر و نگهداری**: توضیح داده شد، اگه بخوای اضافه‌ش می‌کنم.
